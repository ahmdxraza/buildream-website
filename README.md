# 🏗️ Buildream Website

A responsive construction company website inspired by the Buildream template.

## 📌 About

Buildream is a construction website project created using:

- HTML
- CSS
- Animate.css

The website includes a modern construction company layout with responsive design and animations.

## ✨ Features

- Responsive design
- Navigation bar
- Hero section
- About section
- Services section
- Statistics section
- Projects section
- Call-to-action section
- Footer
- Animate.css animations
- Animated buttons
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Animate.css

## 📱 Responsive Design

The website works on:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet
